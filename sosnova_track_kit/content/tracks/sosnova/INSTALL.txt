Autodrom Sosnova - 14.11.2026 layout - Assetto Corsa track (kit version 1.0)

INSTALL
  Copy this whole folder "sosnova" into
    ...\Steam\steamapps\common\assettocorsa\content\tracks\
  so that you get  ...\content\tracks\sosnova\sosnova.kn5
  Start Content Manager -> Drive -> Practice -> track "Autodrom Sosnova - 14.11.2026 layout".

WEATHER / RAIN
  Needs Custom Shaders Patch (0.2.x) and Sol or Pure. Then pick Clear / Overcast / Light rain /
  Rain / Heavy rain in the Weather dropdown. Puddles form in the real hollows of the surface.

AI CARS
  Record the AI line once: Content Manager -> Settings -> Assetto Corsa -> enable Developer apps,
  practice session, open the "AI" app, Start recording, drive one clean lap, Save, then rename
  content\tracks\sosnova\ai\fast_lane.ai.candidate  to  fast_lane.ai

IF THE CARS FACE BACKWARDS AT THE START
  Tell the author; the start dummies need a 180 degree turn (one line in the generator).
