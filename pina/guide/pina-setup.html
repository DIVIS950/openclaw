Set it up

  1. Make Piña's Telegram bot

    • In Telegram, open @BotFather and send /newbot.
    • Name it Piña, then pick a username that ends in bot.
    • BotFather replies with a token like 123456789:AAE…. Copy it.
    • Tap the link to your new bot and press Start, so it is allowed to message you.

  2. Find your Telegram number

    Open @userinfobot and press Start. It replies with your Id, a number. Piña will only ever answer that number.

  3. Get an Anthropic API key

    • Sign in at console.anthropic.com and add some credit under Billing.
    • Set a monthly spend limit, so there are no surprises.
    • Open API Keys, create a key named Piña and copy it. It starts with sk-ant-.

    Piña uses Claude Sonnet 5.5, with Opus 5.5 as a fallback. What it costs depends on how much you use it; the spend limit keeps it in check.

  4. Optional keys

    • Web search: get a free key at aistudio.google.com/apikey. Without it, Piña can still open pages you send it.
    • OpenClaw iPhone app: install Tailscale and sign in. In the Tailscale DNS settings, turn on MagicDNS and HTTPS Certificates. Then generate an auth key (one-off, not ephemeral) and copy it.

  5. Build your server setup

    Paste your keys here. This page puts them into the server setup and copies it for you. Nothing you type is stored or sent anywhere.

    Used for reminders and the morning briefing.

    This text contains your keys. Paste it only into your cloud provider's setup box.

  6. Create Piña's computer

    Any provider with Ubuntu 24.04 and a "cloud config" or "user data" box works. Hetzner is simple and cheap:

    1. Sign in at console.hetzner.cloud and open a project.
    2. Add a server. Pick any location, image Ubuntu 24.04, and a shared type with at least 2 GB RAM (4 GB if Piña will browse a lot).
    3. Keep Public IPv4 switched on. Piña needs it to download its software.
    4. Paste your server setup into Cloud config, name the server pina, and create it.

    DigitalOcean (paste under Advanced, User data) and Oracle Cloud's free Ampere servers work too. AWS's user-data box is too small for this setup.

  7. Say hi

    After about 5 to 10 minutes your bot sends "🍍 Piña is awake on its own computer. Say hi!" Try:

    • "Hi Piña, I'm …. Call me …."
    • "Every day at 7:30 send me a morning briefing."
    • "Remind me tomorrow at 18:00 to call mom."
    • "Find a good pizza place near Wenceslas Square that is open tonight."

    No message after 15 minutes? Check that you pressed Start in your bot, then see Troubleshooting below.

Optional extras

Connect Gmail and Google Calendar

Google requires your own small "app" for this. You make it once in Google Cloud Console:

  1. Open console.cloud.google.com and create a project named Piña.
  2. In APIs & Services, Library, enable Gmail API and Google Calendar API.
  3. Set up the OAuth consent screen: type External, app name Piña, your email. Then publish the app, or the login expires after 7 days.
  4. Under Credentials, create an OAuth client ID of type Desktop app and download its JSON file.
  5. In Telegram, send that file to Piña and say "connect my Gmail and Calendar". Piña sends you a sign-in link and tells you what to paste back.
Google may say the app is unverified. Tap Advanced and continue: it is your own app. Piña drafts emails freely but asks you before sending anything or changing your calendar.
Pair the OpenClaw iPhone app

If you added a Tailscale auth key in step 5, the server is already set up. You get a pairing code in Telegram when Piña wakes up.

  1. Install OpenClaw from the App Store and turn Tailscale on.
  2. In OpenClaw, choose Connect Manually, then Gateway Setup, then Enter setup code. Paste the code from Telegram and tap Trust and connect.
  3. In OpenClaw's Settings, This iPhone, Permissions, grant what you want Piña to use.
  4. The code lasts 10 minutes. For a new one, tell Piña: "send me a new iPhone setup code".

No Tailscale key in step 5? Open your server's console in Hetzner and run sudo bash /opt/pina/iphone-setup.sh. To let Piña add phone calendar events and reminders, add --allow-phone-writes.

Good to know

What an iPhone never allows. No app can tap buttons, read other apps' screens or open other apps. Piña sends notifications, reminders and calendar events instead, or does the job on its own computer.

What Piña can reach. Its own computer, the web, and the accounts you connect. It answers only your Telegram number, and it has no open ports on the internet.

Keys. Your keys live in one locked file on the server, /opt/pina/.env. Piña can technically read them because it runs on that computer, so use a spend limit on Anthropic and a key made only for Piña.

Stopping everything. Delete the server at your provider, revoke the Anthropic key, and send /revoke to BotFather.

Troubleshooting

Open the server console at your provider, log in as root (Hetzner emails you the password), and use these:

tail -n 50 /var/log/pina-setup.log   # what setup did
pina logs                            # Piña's live log
pina channels status --probe         # is Telegram connected?
pina security audit                  # safety check
pina update                          # newer image, same settings
pina backup                          # save Piña's memory and files

Wrong key or number? Edit them with sudo nano /opt/pina/.env, then run sudo bash /opt/pina/setup.sh again. It keeps everything Piña already learned.
